Your rep set is treated as this cycle's week 3 top set (95% TM ×1+) — the training max and every other week's weights are back-calculated from it.

Programme

Scheduling

With 3 days/week the fourth lift rotates in the following week so every lift still gets trained.

5/3/1 for Beginners uses a fixed 3-day split (Squat+Bench practice, Deadlift+Overhead Press, Bench+Squat practice) — the settings above have no effect while it's selected.

Plates on hand

How many of each you own per side (i.e. per one side of the bar). Set to 0 to leave a plate out.

Accessory exercises

Attached to each lift's day and applied across every week. Give an exercise a weight and it's folded into that day's plate loading; leave it unweighted for bodyweight or machine work.

Plate loading is sequenced to minimise changes between sets, not just picked from the heaviest plate down. Independent build — not affiliated with Jim Wendler or any 5/3/1 app.
